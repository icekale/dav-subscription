# Web 前端手机端用户体验优化 设计文档

> 日期：2026-08-06 · 状态：已批准

## 目标

让普通用户能在**手机浏览器**上方便地完成核心操作：浏览订阅广场、搜索、订阅/取消、切换订阅类型、特别关注、查看动态、配置推送渠道。当前手机端仅把侧边栏收成纯图标列（无文字标签），普通用户导航困难、操作不便。

## 范围

只优化**普通用户**相关页面；后台管理页面不重做布局（仅作为管理员在手机端的「更多」入口进入）。桌面端（>768px）行为完全保持不变。

## 1. 导航与信息架构

- 手机端（`max-width: 768px`）：隐藏 `.sidebar`，底部固定标签栏 `.bottom-nav`，5 个标签：
  广场（`#/home`）、组合（`#/combinations`）、订阅（`#/mysubs`）、动态（`#/timeline`）、设置（`#/settings`）
- 管理员额外显示第 6 个「更多」标签（`#/admin/stats` 作为入口，内含后台 9 个页面），普通用户不显示
- 底部栏当前路由高亮；底部 `env(safe-area-inset-bottom)` 适配 iPhone 手势区
- 桌面端（>768px）：保持现有侧边栏，`.bottom-nav` 不显示

## 2. 各页面手机布局

- **订阅广场**：搜索框通栏；平台筛选改为带文字的可横滑 chips（全部/雪球/雪球组合/微博/X）；KOL 卡片单列全宽（头像 + 名称 + 平台 + ID + 分类），订阅按钮通栏（≥44px，已订阅显示「已订阅 ✓」、可再点取消）
- **组合订阅**：卡片化展示（名称/主理人/年化/净值），点击进详情
- **我的订阅**：顶部「全部/组合/大V」分段控件；每项含名称平台、订阅类型三段选择（帖子/回复/帖子+回复）、特别关注⭐、取消订阅；触控目标 ≥44px
- **动态**：帖子卡片单列，标题/正文/时间/原文链接可点
- **推送设置**：表单控件 ≥44px；「生成绑定码」通栏醒目按钮；各渠道绑定状态卡片化
- **搜索 / 大V详情页**：保持现有结构，微调触控目标

## 3. 技术实现

- `index.html`：新增 `<nav id="bottom-nav">` 容器（仅移动端渲染显示）
- `app.js`：
  - 新增 `renderBottomNav(user)`，渲染 5 个标签 + 管理员「更多」，按当前 hash 高亮
  - `renderSidebar` 与 `renderBottomNav` 共用路由表（现有 `NAV_ITEMS` 扩展出移动端分组）
  - 登录态变化后同步刷新底部栏
- `style.css`：
  - `@media (max-width: 768px)`：`.sidebar { display:none }`、`.bottom-nav { display:flex }`、`.main-col` 留出底部空间
  - `.bottom-nav`：固定底部、`padding-bottom: env(safe-area-inset-bottom)`、标签 ≥44px
  - 移动端统一触控目标 `min-height:44px`
  - 平台筛选 chips 移动端显示文字标签（现有 `.platform-tab` 移动端样式补充 label）
  - 订阅按钮 `.btn-sub` 移动端通栏（现有 640px 规则扩展/调整到 768px）
- 路由复用现有 hash 路由，无后端改动

## 4. 测试与验收

- 前端无自动化测试：`node --check` 校验 JS；GitHub CI 已有 node 语法检查步骤
- 手工走查（开发者工具响应式 375/390px + 桌面宽度）：
  - 手机尺寸：侧边栏隐藏、底部栏出现，5 标签可切换且高亮；管理员见「更多」并可进 9 个后台页、可返回；普通用户无「更多」
  - 平台 chips 横滑、带文字、筛选生效
  - KOL 卡片单列，订阅/取消可点（≥44px）
  - 我的订阅分段控件、类型、⭐、取消可点
  - 动态卡片正文与原文链接可点
  - 设置表单 ≥44px、绑定码按钮通栏
  - 模拟 iPhone 底部安全区不遮挡
  - 桌面宽度恢复侧边栏、现有功能不回归
- 部署：同既有流程，同步 unraid 重建后走查

## 不做（YAGNI）

- 后台管理页面的移动端重设计（仅做入口）
- 深色模式、PWA、离线缓存
- 触摸滑动类手势（除 chips 横滑）
- 后端任何改动
