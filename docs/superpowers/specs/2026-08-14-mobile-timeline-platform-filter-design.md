# 移动端动态广场轻量平台筛选设计

## 目标

降低移动端动态广场二级筛选面板的视觉和操作负担。移动端用户点击“筛选”后，只选择内容平台，不再处理关键词、分类和标签。

## 交互

- 仅在视口宽度不超过 768px 时启用轻量模式。
- 点击“筛选”展开一行五个平台角标：全部、雪球、雪球组合、微博、X。
- 复用现有 `PLATFORM_ICONS`，不新增图标资产。
- 每个角标触控区至少 44×44px，并提供 `aria-label`、`title` 和 `aria-pressed`。
- 点击角标立即应用平台筛选并收起面板，不再要求点击“完成”。
- 选中平台时，“筛选”按钮继续显示激活态；选择“全部”后取消平台激活态。
- 移动端打开轻量筛选时，自动清除关键词、分类和标签条件，避免不可见条件继续影响结果。

## 响应式边界

- 桌面端保持现有完整筛选：平台胶囊、关键词、分类、标签、清除和完成按钮。
- 移动端不渲染搜索框、分类、标签、清除和完成按钮，避免仅靠 CSS 隐藏产生不可见可聚焦控件。

## 视觉

- 平台角标为一行五列等宽布局。
- 未选中态使用白色/深色主题 surface、细边框和现有平台品牌色。
- 选中态使用实心通知蓝与白色图标。
- 不增加卡片、阴影或说明文字。

## 验收

- 390px 视口无横向溢出，五个角标完整显示。
- 每个角标触控高度至少 44px。
- 点击任一角标后请求只携带该 `platform`，关键词、分类和标签为空。
- 选择“全部”后平台参数为空。
- 桌面端现有完整筛选功能不变。
- 键盘与读屏可识别每个平台及选中状态。
