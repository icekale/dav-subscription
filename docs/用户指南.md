# 用户指南

V Push：关注雪球 / 微博 / X 上的大V，新帖第一时间推送到你的 Telegram、飞书或企业微信群。

## 一、Telegram 订阅

1. 在 Telegram 里搜索机器人并打开，发送任意消息（如 `/start`），系统自动记录你的会话。
2. 发 `/list` 查看可订阅的大V（大V多时用 `/list 2` 翻页，或点下方按钮翻页）。
3. 发 `/sub 大VID` 订阅，例如 `/sub 1`；也可以用雪球主页链接 `/sub https://xueqiu.com/u/12345`。
4. 之后该大V的新帖会自动推送到你的 Telegram。

常用命令：

- `/list` — 查看可订阅的大V（`/list 2` 翻页）
- `/sub 1` / `/sub 链接` — 订阅
- `/unsub 1` — 取消订阅
- `/mysubs` — 我的订阅
- `/bind 6位码` — 把机器人账号合并到网页/小程序账号
- `/help` — 帮助

## 二、飞书订阅

1. 在飞书里搜索机器人并打开，发送任意消息（如 `/start`）。
2. 发 `/list`，会收到一张带按钮的交互卡片，直接点「订阅」即可；点「下一页」翻页。
3. 发 `/sub 大VID` 或点卡片按钮订阅，新帖会推送到你的飞书单聊。

## 三、企业微信订阅（群机器人）

企业微信通过「群机器人」接收推送，推送会发到机器人所在的群，适合团队/群组共享订阅。

1. 打开企业微信，进入一个群（没有就新建一个，例如「大V推送」）。
2. 点右上角 `...` →「群机器人」→「添加机器人」，按提示创建并起名。
3. 复制创建完成后给出的 webhook 地址（`https://qyapi.weixin.qq.com/cgi-bin/webhook/send?key=...`）。
4. 在网页后台「推送设置」把 webhook 粘贴到「企业微信」输入框，点「保存绑定」。

> 群机器人 webhook 等同群管理权限，请勿泄露给他人；每个用户应使用各自的群机器人。企业微信群机器人是单向 webhook，不支持 `/sub` 等指令，订阅请在网页/小程序完成。

## 四、网页/小程序使用

1. 打开网页后台地址（管理员提供），注册或登录账号。
2. 在「订阅广场」浏览并订阅大V；「动态」看已订阅大V的最新帖。
3. 在「推送设置」：
   - 查看当前绑定的 Telegram / 飞书渠道状态；
   - 点「生成绑定码」，把 `/bind 6位码` 发给机器人，即可把该渠道合并到当前账号——之后**网页上订阅一次，Telegram 和飞书都能收到推送**。
   - 可修改密码、关闭推送。

> 💡 **飞书个人机器人（推荐，如服务端已启用）**：在「推送设置 → 渠道绑定 → 飞书」里点「扫码创建个人机器人」。
> 用飞书扫码后，飞书会在你的租户自动创建**属于你自己的机器人应用**，推送配额独立、不受共享机器人限频影响。
> 创建后在个人机器人私聊窗口发送网页显示的 `/bind 6位码` 即可完成绑定；失败或解绑都会自动回退到共享机器人，不影响既有绑定。

## 五、常见问题

- **推送没收到？** 先确认「推送设置」里渠道显示已绑定；飞书需要先给机器人发过消息（记录单聊会话）。可以让管理员用「测试推送」验证。
- **一个账号想同时收 TG 和飞书？** 分别给两个机器人发消息，再在网页生成绑定码，分别 `/bind` 到同一个网页账号即可。
- **Telegram 收不到？** 通常是网络原因，管理员配置代理（TELEGRAM_PROXY）后即可恢复。
